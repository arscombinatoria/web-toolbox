This list is based on the upstream codec Cargo.toml and its locked build. The application uses the freestanding single-thread build (default features off); optional rayon/crossbeam parallel dependencies and command-line/build-only crates are not linked into the shipped single-thread Wasm. The full notice files for the selected MIT terms are reproduced below. Dual-licensed crates use their MIT alternative.

Known-advisory checks performed 2026-11-25:
- GitHub advisory searches for the exact npm package @jsquash/oxipng 2.3.0 and embedded Oxipng package returned no matching advisories.
- OSV batch review of the upstream Cargo.lock found crossbeam-channel 0.5.13 (GHSA-pg9f-39pc-qf8g / RUSTSEC-2025-0024) and crossbeam-epoch 0.9.18 (RUSTSEC-2026-0204). These are reachable from the optional parallel/rayon feature, which this app's single-thread `freestanding` build disables. This check is package-specific, not a full security audit.
